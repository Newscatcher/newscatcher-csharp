## 2.0.0 - 2026-03-16
* The `AggregationClient` class has been removed from the SDK, along with the `GetAsync` and `PostAsync` methods for article aggregation count operations. Consumers using aggregation endpoints will need to implement custom HTTP calls or migrate to alternative endpoints for similar functionality.
* The `LatestheadlinesClient` class has been removed from the SDK. Applications using `client.Latestheadlines.GetAsync()` or `client.Latestheadlines.PostAsync()` methods will need to be updated to use alternative endpoints or a different client implementation for accessing latest headlines functionality.
* The deprecated `SearchGetRequest` class and `SearchLinkClient` have been removed from the SDK. Applications using these components must migrate to the updated search functionality available in the current API.
* The SearchSimilar API functionality has been removed from the SDK. The `SearchsimilarClient` class and its `GetAsync()` and `PostAsync()` methods are no longer available. Applications using search similar functionality will need to be updated to use alternative search methods or directly call the API endpoints.
* Several public types have been removed from the SDK: FailedSearchSimilarResponseDto, SearchSimilarResponseDto, SimilarArticleEntity, SimilarDocument, and the PublishedDatePrecision enum. If your application references these types, you will need to remove those references as the search similar functionality is no longer supported. Additionally, AggregationPostRequest has been renamed to PostAggregationCountRequest - update any direct references to use the new name.
* The SDK now provides access to raw HTTP response metadata through a new response wrapper. All client methods now return WithRawResponseTask objects that include both the deserialized response data and raw HTTP details like status codes, headers, and URLs. New AllLinksText parameter added to author search requests for filtering by link text content.
* The SDK now supports async header value resolution through new ValueTask and Task-based HeaderValue constructors. Enhanced retry logic includes intelligent exponential backoff with jitter and respect for server-provided Retry-After headers. Improved JSON serialization handles Optional types more accurately and provides better performance with relaxed escaping options.
* Breaking changes to request types and client structure. Request classes have been renamed (e.g. SearchPostRequest → PostSearchRequest, LatestHeadlinesPostRequest → PostLatestHeadlinesRequest). Client properties have been renamed (Latestheadlines → LatestHeadlines, SearchLink → SearchByLink, Aggregation → AggregationCount). The Theme and NotTheme properties now accept string instead of OneOf<string, IEnumerable<string>>. Update your code to use the new type names and property types.
* Breaking changes to request types and method signatures. The `SourcesGetRequest` class has been renamed to `GetSourcesRequest` and `SourcesPostRequest` has been renamed to `PostSourcesRequest`. All API methods now return `WithRawResponseTask<T>` instead of `Task<T>` to provide access to raw HTTP response details. Exception types have changed from `NewscatcherApiException` to `NewscatcherApiApiException`. Update your code to use the new request type names and handle the new response wrapper format.
* The AdditionalProperties property on all response types has been changed from a mutable IDictionary<string, JsonElement> to a ReadOnlyAdditionalProperties wrapper. Existing code that writes to AdditionalProperties will no longer compile. The Content property in BreakingNewsArticleEntity is now nullable instead of required. The RobotsCompliant property has been removed from BreakingNewsArticleEntity. Enum types ClusteringVariable, NewsDomainType, and SortBy have been converted to string-based readonly record structs with different comparison semantics.
* The SDK now provides improved serialization handling with a new ReadOnlyAdditionalProperties type that replaces the experimental AdditionalProperties. Enhanced query string processing now supports prefixed deep object notation for more flexible parameter encoding.
* New AggregationCount and Authors API clients are now available. The AggregationCount client enables retrieving article counts aggregated by day or hour with extensive filtering options. The Authors client provides search functionality for articles by specific authors with comprehensive filtering capabilities including language, country, source, sentiment analysis, and more.
* New author search and breaking news APIs are now available. The SDK supports comprehensive filtering options including geographic targeting, language selection, sentiment analysis, and content categorization through IPTC and IAB tags. Breaking news retrieval includes real-time updates with pagination and ranking capabilities.
* The SDK now includes core infrastructure for optional parameters, additional properties, and raw HTTP response access. New types include `OptionalAttribute`, `AdditionalProperties`, `RawResponse`, `WithRawResponse`, and `ResponseHeaders` to support enhanced SDK functionality.
* New `ISearchClient` and `ILatestHeadlinesClient` interfaces provide comprehensive news search and headline retrieval capabilities. The Search client supports keyword-based article search while the LatestHeadlines client retrieves recent articles for specified time periods. Both clients offer extensive filtering options including language, country, source, sentiment analysis, NLP data, and clustering features.
* The SDK now includes three new client modules: SearchByLink for finding articles by ID or URL, Sources for retrieving news source information, and Subscription for accessing subscription plan details. Each client provides async methods with comprehensive error handling and cancellation token support.
