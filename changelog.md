## 2.0.0 - 2026-03-16
* The `AggregationGetRequest` class, `LatestheadlinesClient` class, and several enum types (`AggregationGetRequestPublishedDatePrecision`, `AggregationGetRequestSortBy`, `AuthorsGetRequestPublishedDatePrecision`, `AuthorsGetRequestSortBy`, `BreakingNewsGetRequestSortBy`) have been removed. Applications using these types will need to be updated to use alternative request classes or methods.
* Several request types and the SearchLinkClient have been removed from the SDK. Applications using LatestHeadlinesGetRequest, SearchGetRequestClusteringVariable, SearchGetRequestNewsDomainType, SearchGetRequestPublishedDatePrecision, SearchGetRequestSortBy, or the SearchLinkClient class will need to be updated to use alternative API methods.
* The SearchSimilar functionality has been removed from the SDK. The `SearchsimilarClient` class and its `GetAsync()` and `PostAsync()` methods are no longer available. Applications using these methods should remove the related code or find alternative approaches for similar document search functionality.
* The SearchSimilar API types have been removed as this functionality is no longer supported by the service. The following types are no longer available: `FailedSearchSimilarResponseDto`, `SearchSimilarResponseDto`, `SimilarArticleEntity`, `SimilarDocument`, and `PublishedDatePrecision`. If you were using these types, please migrate to alternative search methods available in the SDK.
* The AggregationClient now implements the IAggregationClient interface and provides access to raw HTTP responses through WithRawResponse wrappers. Method names have been updated for clarity (GetAsync → CountGetAsync, PostAsync → CountPostAsync) and request types have been renamed accordingly. A new AllLinksText parameter is available for enhanced search capabilities.
* The AuthorsClient now returns response metadata including HTTP status codes, headers, and URLs. A new optional `all_links_text` parameter is available for filtering articles by link text content.
* New `AllLinksText` parameter added for searching article link anchor text content. Date/time parameters (`From`, `To`) now accept both DateTime objects and string values for flexible input formats. Enhanced response handling with raw response access through `WithRawResponseTask` wrapper.
* Breaking changes to BreakingNews request models: The `SortBy` property now uses the `SortBy` enum instead of `BreakingNewsGetRequestSortBy`. The `Theme` and `NotTheme` properties are now `string` types instead of `OneOf<string, IEnumerable<string>>`. The `RobotsCompliant` property has been removed from both GET and POST request models. Additionally, the `ContentSentientMax` property in POST requests has been renamed to `ContentSentimentMax`.
* The SDK now supports flexible date input formats for From and To parameters, accepting both DateTime objects and date strings. Added new AllLinksText parameter for searching article link anchor text. Updated type definitions for better extensibility and consistency.
* The SearchClient now implements ISearchClient interface for improved testability and dependency injection. Raw HTTP response metadata is now accessible through new WithRawResponse wrapper methods. Request types have been renamed for clarity (SearchUrl* to SearchByLink*).
* The SDK now provides access to raw HTTP response data including status codes, headers, and URLs through a new `WithRawResponse` wrapper. New fields have been added to response models for enhanced article and source information.
* Breaking changes to enum types and additional properties handling. Enum types (ClusteringVariable, NewsDomainType, SortBy) are now string enum structs instead of traditional enums, which may require code changes for switch statements and comparisons. The experimental AdditionalProperties field has been replaced with a ReadOnlyAdditionalProperties wrapper that provides read-only access.
* The SDK now supports three new client interfaces: IAggregationClient for article count aggregation, IAuthorsClient for author-based article searches, and IBreakingNewsClient for breaking news retrieval. All clients provide flexible filtering options with enhanced OneOf type support for date parameters.
* The SDK now supports Optional<T> types for distinguishing between undefined and null values in API requests. Use Optional<T>.Undefined to omit fields from requests, or Optional<T>.Of(value) to explicitly send values (including null). New RawResponse and WithRawResponse types provide access to HTTP response metadata like status codes and headers.
* New LatestHeadlines client available for retrieving recent news headlines with comprehensive filtering options. The client supports filtering by language, country, sources, sentiment analysis, named entities, and more. Includes advanced clustering capabilities and NLP data integration for enhanced news analysis.
* New client interfaces and request types are now available for search, search by link, sources, and subscription operations. The SDK now provides structured access to advanced filtering options including language, country, source, and content parameters.
