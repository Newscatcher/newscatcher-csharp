## 2.0.0 - 2026-03-19
* The Aggregation API client has been removed from the SDK. Applications using `AggregationClient.GetAsync()` or `AggregationClient.PostAsync()` methods will need to migrate to alternative endpoints or implement custom HTTP calls to the aggregation endpoints.
* The `LatestheadlinesClient` class has been removed from the SDK, including the `GetAsync()` and `PostAsync()` methods for retrieving latest headlines. All related request types (`LatestHeadlinesGetRequest`, `LatestHeadlinesGetRequestClusteringVariable`) are also no longer available. Any code using these APIs will need to be updated to use alternative methods for accessing latest headlines functionality.
* The `SearchGetRequest` class and `SearchLinkClient` have been removed from the SDK. Applications using these types will need to migrate to alternative search implementations. The removed enums `SearchGetRequestClusteringVariable`, `SearchGetRequestNewsDomainType`, `SearchGetRequestPublishedDatePrecision`, and `SearchGetRequestSortBy` are also no longer available.
* The SearchSimilar API functionality has been removed from the SDK. The `SearchsimilarClient` class and all related methods (`GetAsync`, `PostAsync`) are no longer available. Applications using these methods will need to be updated to use alternative search functionality or remove the dependent code.
* The SDK now provides aggregation count functionality through the new `PostAggregationCountRequest` endpoint, replacing the previous search similar API. Several response types related to similar document searching have been removed: `FailedSearchSimilarResponseDto`, `SearchSimilarResponseDto`, `SimilarArticleEntity`, `SimilarDocument`, and `PublishedDatePrecision`. The aggregation count request now includes enhanced filtering with `all_links_text` parameter and simplified theme filtering using string types.
* The SDK now provides access to raw HTTP response metadata through the new `WithRawResponse` wrapper. All client methods now return response objects that include status codes, headers, and URLs alongside the parsed data. New `AllLinksText` parameter added to author search requests for enhanced filtering capabilities.
* The SDK has been updated to improve type safety and consistency. Request class names now follow consistent patterns, and all clients implement interfaces. Existing method signatures remain unchanged, so no code changes are required when upgrading.
* The Sources request types have been renamed for consistency: `SourcesGetRequest` is now `GetSourcesRequest` and `SourcesPostRequest` is now `PostSourcesRequest`. Update your code to use the new class names. Additionally, client methods now return wrapped responses that provide access to raw HTTP response data alongside the parsed response.
* New translation fields available on breaking news articles. When setting the `include_translation_fields` parameter to true, the SDK now provides `TitleTranslatedEn` and `ContentTranslatedEn` properties containing English translations of article titles and content. The `Content` property on `BreakingNewsArticleEntity` is now nullable to better reflect optional content availability. Additional properties on response models are now encapsulated with improved type safety.
* The `AdditionalProperties` property on response objects has been changed from a mutable `IDictionary<string, JsonElement>` to a read-only `ReadOnlyAdditionalProperties` wrapper. If your code modifies additional properties directly, you'll need to update it to use the provided methods on the new wrapper type.
* The SDK now includes two new client modules: `AggregationCountClient` for retrieving article counts aggregated by day or hour, and `AuthorsClient` for searching articles by specific authors. Both clients support comprehensive filtering options including language, country, source, and date range parameters.
* New Authors and BreakingNews clients are now available. The Authors client allows filtering news articles by author names with advanced filtering options. The BreakingNews client provides access to real-time breaking news content with both GET and POST endpoints.
* The SDK now includes enhanced infrastructure for optional properties, additional properties handling, raw HTTP response access, and improved query string building performance. New WithRawResponse methods allow accessing both parsed data and HTTP metadata when needed.
* The SDK now includes Search and LatestHeadlines clients for comprehensive news search functionality. SearchClient enables keyword-based article searches while LatestHeadlinesClient retrieves recent news filtered by time periods. Both clients support extensive filtering options including language, country, source filtering, sentiment analysis, and content categorization.
* The SDK now supports searching for articles by link or ID through the new `SearchByLinkClient`. Additional client interfaces for `SourcesClient` and `SubscriptionClient` are also available for managing news sources and subscription information.
